# Barbearias-Landing-page # 💈 Império Barber

Landing page moderna desenvolvida para uma barbearia premium, com foco em identidade visual forte, experiência do usuário e conversão de clientes.

O projeto foi criado para transmitir elegância, presença, exclusividade e profissionalismo através de uma interface moderna, responsiva e visualmente impactante.

## 🚀 Funcionalidades

### Hero Section

* Banner principal de destaque
* Chamadas para ação estratégicas
* Visual premium e imersivo

### Serviços

* Exibição dos principais serviços
* Cards interativos
* Destaque de preços

### Sobre a Barbearia

* Apresentação institucional
* Posicionamento da marca
* Design moderno e elegante

### Galeria

* Exibição de cortes realizados
* Layout responsivo
* Efeitos visuais suaves

### Agendamento

* Formulário para solicitação de horário
* Validação de dados via JavaScript
* Interface simples e intuitiva

### Contato

* Integração com WhatsApp
* Acesso rápido ao Instagram
* Informações da barbearia
